# BoozyDB

A cocktail recipe catalog with a responsive static web app and a Python CLI. Browse a curated collection of classic and modern recipes with glass illustrations, ingredient lists, and step-by-step instructions — no database setup required.

Licensed under [GNU AGPL v3](LICENSE.md).

---

## Live Site

The web catalog is served from the `docs/` folder and deployable directly to GitHub Pages.

**Features:**
- Search by name, spirit, or flavor tags
- Filter by spirit type
- Dark and light themes
- SVG glass illustrations with liquid fills
- Method badges (Shaken / Stirred / Built / Blended)
- Spirit color coding
- Slide-over recipe modal with shareable deep links (`#/recipe/<uuid>`)
- Fully responsive (desktop, tablet, mobile)
- Terminal easter egg — press `` ` `` for CLI mode

### Deploy to GitHub Pages

1. Push to `main`
2. Go to **Settings → Pages → Branch: main, Folder: /docs**
3. Site goes live at `https://<username>.github.io/<repo>/`

## CLI

The CLI manages the recipe catalog from the terminal.

```bash
boozydb list                    # Show all recipes in a table
boozydb list --spirit gin       # Filter by spirit type
boozydb show negroni            # Display full recipe details
boozydb add                     # Interactively add a new recipe
boozydb edit negroni            # Edit an existing recipe
boozydb delete negroni          # Delete a recipe
boozydb random --tag classic    # Random recipe with filters
```

```
├── docs/                    # Static site (GitHub Pages source)
│   ├── index.html           # Self-contained SPA (all CSS + JS inline)
│   └── recipes.json         # Pre-built recipe data (generated by build.py)
├── src/boozydb/             # Python CLI
│   ├── cli.py               # Typer CLI entry point
│   ├── models.py            # Pydantic recipe validation
│   ├── query.py             # Filtering and sorting
│   ├── render.py            # Rich terminal rendering
│   └── storage/             # JSON backend
├── data/
│   ├── recipes/             # JSON recipe files (UUID-named)
│   └── templates/           # Recipe schema reference
├── tests/                   # pytest unit tests
├── build.py                 # Regenerates docs/recipes.json from data/recipes/
└── pyproject.toml           # Dependencies and build config
```

## Adding Recipes

Recipes are stored as individual JSON files in `data/recipes/`. After adding or editing any recipe, run the build script to update the web catalog:

```bash
python build.py
```

**Recipe Schema:**
```json
{
  "id": "uuid-here",
  "name": "Recipe Name",
  "spirit": "gin",
  "glass": "coupe",
  "tags": ["classic", "citrus"],
  "ingredients": [
    { "amount": "2", "unit": "oz", "item": "gin" },
    { "amount": "0.75", "unit": "oz", "item": "lime juice" }
  ],
  "instructions": [
    "Add ingredients to shaker with ice.",
    "Shake until chilled.",
    "Strain into coupe."
  ],
  "source": "Optional attribution",
  "created_at": "2025-12-21T04:25:35+00:00"
}
```
